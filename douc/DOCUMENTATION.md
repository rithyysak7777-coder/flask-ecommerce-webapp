# Flask E-Commerce Web Application - Technical Documentation

## 1. Project Overview
This web application is a full-featured E-Commerce and User Management system built with **Python Flask**, **Flask-SQLAlchemy**, **Flask-Migrate**, and **Jinja2 Templates**. It was developed for the Setec Year 3 (2026) Semester 2 Python course.

The system features a customer-facing storefront with dynamic shopping cart capabilities, user authentication, checkout workflows integrated with Telegram notifications, and a dedicated Back-Office Admin Management interface for managing application users.

## 3. Technology Stack & Dependencies

- **Backend Framework**: Python Flask 3.x
- **Database / ORM**: SQLite (`mydb.sqlite3`) with `Flask-SQLAlchemy`
- **Database Migrations**: `Flask-Migrate` (SQLAlchemy / Alembic integration)
- **Session & Cookie Management**: Browser HTTP cookies for cart storage, Flask Server Session (`app.secret_key`) for active user logins and order snapshots.
- **External Integration**: Telegram Bot API (`requests` library) for real-time order alerts sent directly to Telegram Channel `@RACTZ_STORE`.
- **Frontend / Templating**: HTML5, CSS3, Jinja2 Template Inheritance (`master.html`, header/footer/navbar partials).

## 4. Comprehensive Folder & Component Guide

### 🛠️ Core Application Files
- 📄 **`app.py`**: **Main Entry Point** — Configures Flask server, SQLite connection, SQLAlchemy models (`User`), customer storefront routes, dynamic cookie cart logic, Telegram order notifications, admin authentication (`@login_required`), admin login/logout, and admin user CRUD routes.
- 📄 **`product.py`**: **Catalog Manager** — In-memory catalog dataset array and utility helper functions (`get_product_by_id()`, `get_product_by_category()`).
- 📄 **`memory_store.py`**: **JSON File Helper** — Functions (`load_users()`, `save_users()`) to read/write customer accounts in `data/users.json`.

### 📁 Data & Database Directories
- 📁 **`data/`**: Stores local JSON database files (`users.json` for customer profiles & order snapshots).
- 📁 **`instance/`**: Contains `mydb.sqlite3`, the active SQLite database created and updated by SQLAlchemy.
- 📁 **`migrations/`**: Generated by `Flask-Migrate` (Alembic) to record database schema migration histories.

### 🎨 Static Web Assets (`static/`)
- 📁 **`static/css/`**: Public stylesheets (`style.css`) for customer storefront styling.
- 📁 **`static/admin css/`**: Dedicated admin stylesheets (`logincss.css`, `adminstyle.css`) for back-office panel and login page.
- 📁 **`static/images/`**: Upload directory for user profile avatars and store media.
- 📁 **`static/js/`**: Client-side scripts for dynamic interactivity and AJAX shopping cart updates.

### 🖼️ Jinja2 HTML Templates (`templates/`)
- 📁 **`templates/front/`**: **Storefront Views**
  - **Main Pages**: `home.html`, `products.html`, `product_detail.html`, `cart.html`, `checkout.html`, `payment.html`, `account.html`, `search.html`.
  - **Auth Pages**: `login.html`, `register.html`, `reset_password.html`.
  - **Shared Components (`templates/front/share/`)**: `header.html`, `footer.html`, `navbar.html`.
- 📁 **`templates/admin/`**: **Admin Panel Views**
  - **Core Layout**: `master.html` (Master wrapper template), `login.html` (Admin authentication page).
  - **User CRUD (`templates/admin/user/`)**: `user.html` (Read), `add.html` (Create), `edit.html` (Update), `comfirm_delete.html` (Delete), `profile.html` (View profile).
  - **Shared Components (`templates/admin/share/`)**: `header.html`, `footer.html`, `navbar.html`, `sidebar.html`, `script.html`.

## 5. Key Functional Modules

### A. Storefront & Catalog Management
- **Home & Products**: Dynamic filtering by category (`men's clothing`, `jewelery`, etc.).
- **Product Detail**: Displays detailed item view with related products from the same category.
- **Search System**: Search functionality across products.

### B. Dynamic Cookie-Based Shopping Cart Algorithm
- Cart items are stored in client-side cookies (`cart_list`) as JSON `[{"id": "...", "qty": 1}]`.
- Automatic deduplication and quantity merging when duplicate items are added.
- Live calculation of **Subtotal**, **10% Discount**, **Shipping** ($0 if order >= $150, else $12), and **7% Estimated Tax**.
- Supports AJAX/XMLHttpRequest responses for instant front-end cart UI updates.

### C. Telegram Bot Checkout Integration
- Upon customer checkout (`POST /checkout`), order details (Customer info, items, totals) are formatted into HTML.
- Uses Telegram Bot API to automatically broadcast real-time notifications to Telegram channel `@RACTZ_STORE`.
- Order snapshot is saved to Flask `session` and client cart cookie is cleared.

### D. User Authentication System
- Customer registration and login using `memory_store.py` (`data/users.json`).
- Session management (`session['user']`) for protecting account pages.
- Password reset link handler simulation.

### E. Admin Portal & User Authentication System
- **Admin Authentication & Session Protection**:
  - **Route Security (`login_required`)**: Admin routes (`/admin/dashboard`, `/admin/user`, `/admin/order`, `/admin/product`, etc.) are protected with `@login_required` decorator which verifies `session.get('is_login')`. Unauthenticated requests are automatically redirected to `/admin/login`.
  - **Admin Login (`POST /admin/login`)**: Queries user credentials via SQL, safely maps tuple rows to dictionaries (`dict(result._mapping)`), verifies passwords using `check_password_hash` with plain-text fallback, and initializes admin session variables.
  - **1-Day Persistent Session**: Enables `session.permanent = True` during login so that sessions persist across browser restarts for 1 day (`PERMANENT_SESSION_LIFETIME = timedelta(days=1)` / 1440 minutes).
  - **Admin Logout (`GET /admin/logout`)**: Clears session data (`session.clear()`) and redirects back to `/admin/login`.

- **Database Model (`User`)**:
  - `id`: Integer Primary Key
  - `username`: String(80)
  - `email`: String(120), Unique
  - `password`: String(255)
  - `role`: String(80)
  - `profile`: String(255)
  - `status`: String(80)
- **User Profile Image Processing & Path Protection**:
  - **5MB File Size Limit**: Enforces a strict 5MB file upload validation limit per image.
  - **Dual-Version Image Generation**:
    - **Original Version (100% Quality)**: Saved as `static/images/{user_id}_org_{username}.{ext}` (Full resolution for Detail `profile.html` & Edit `edit.html` views).
    - **Thumbnail Version (-80% Quality Reduction)**: Resized down to max 150x150 pixels and saved as `static/images/{user_id}_thum_{username}.jpg` at 20% JPEG quality using Pillow for fast loading in the User Directory table (`user.html`).
  - **Secure Photo Serving Route (`user_photo`)**: Serves profile images via `@app.get('/admin/user/photo/<int:user_id>/<string:photo_type>')` to obfuscate internal filesystem paths and protect system file structures from browser source code inspection.

- **User CRUD Features**:
  - **List Users** (`GET /admin/user`): Executes SQL queries `SELECT * FROM user` mapped to dictionaries and displays 80% quality reduced thumbnails (`thum`).
  - **Add User** (`GET/POST /admin/user/add`): Creates a new `User` ORM instance, processes dual image versions, and commits to SQLite.
  - **Edit User** (`GET/POST /admin/user/edit/<user_id>`): Updates existing user records and profile photos.
  - **Delete User** (`GET /admin/user/confirm-delete/<user_id>`, `POST /admin/user/delete`): Confirmation view before permanently deleting a user.
  - **User Profile** (`GET /admin/user/profile/<user_id>`): Views detailed user information with 100% full quality original photo (`org`).

## 6. How to Setup and Run the Application

1. **Install Dependencies**:
   ```bash
   pip install flask flask-sqlalchemy flask-migrate requests
   ```

2. **Initialize Database**:
   ```bash
   flask db init
   flask db migrate -m "Initial migration"
   flask db upgrade
   ```

3. **Run Application**:
   ```bash
   python app.py
   ```
   Access application at `http://127.0.0.1:5000/`.
